# MLPRO-GSM — GitHub Pages

Catalogue MLPRO-GSM avec 25 services, prix de revente en FCFA, recherche, catégories et commande WhatsApp.

## Fichiers
- index.html
- css/style.css
- js/app.js
- assets/images/

## GitHub Pages
1. Crée un dépôt GitHub.
2. Envoie tous les fichiers à la racine du dépôt.
3. Settings → Pages.
4. Deploy from a branch → `main` → `/ (root)`.
5. Enregistre.

## Modifier les prix
Tous les services et prix sont dans `js/app.js`, dans `products`.
